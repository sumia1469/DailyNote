# 사용자 온보딩

## 1. 계정 만들기와 첫 로그인

로그인 화면의 사용자 등록신청을 열어 아이디와 8자 이상 비밀번호·확인을 입력합니다. 제출하면 승인 대기 상태입니다. 관리자의 승인 전에는 로그인할 수 없습니다. 승인 후 아이디·비밀번호로 로그인하면 일일리스트가 열립니다. 임시 비밀번호로 초기화된 계정은 로그인 직후 본인 비밀번호로 변경해야 합니다.

## 2. 공통 화면 읽기

왼쪽 둥근 메뉴 버튼은 PC·모바일 모두 숨김 메뉴를 엽니다. 중앙 제목은 현재 화면명입니다. 작은 DailyNote 표시 아래 큰 제목이 반복되지 않습니다. 우측 ＋는 현재 메뉴에 등록 가능한 항목을 만드는 팝업입니다. 공지 조회나 설정 메뉴에는 불필요한 ＋가 없습니다. 메뉴는 바깥 영역, 닫기, Escape로 닫습니다. 키보드는 Tab으로 이동합니다.

## 3. 첫 일지 등록

일일리스트 우측 ＋를 누릅니다. 업무일자를 선택하고 TODO를 한 줄에 하나씩 적습니다. 익일 계획은 내일 해야 할 일, 비고는 짧은 참고 정보, 메모는 자세한 내용입니다. 목록의 상위로·하위로 버튼으로 들여쓰기하며 PC에서는 Tab·Shift+Tab도 사용할 수 있습니다. 등록을 누르면 팝업이 닫히고 카드가 표시됩니다.

## 4. 일지 사용 습관

체크박스로 완료 표시하고, TODO 문구를 눌러 직접 수정합니다. 카드 …에서 오늘 날짜 복제·수정·내용 복사·접기·삭제를 선택합니다. 복제 시 완료 항목을 제외할지 선택할 수 있고 원본은 유지됩니다. 삭제 전 내용을 확인하세요. 날짜 검색은 상단 돋보기 → 업무일자 입력칸 → 달력에서 날짜 선택 → 조회입니다. 돋보기는 검색창만 열고 달력은 날짜 입력칸을 눌렀을 때 표시됩니다. 전체를 누르면 검색 조건을 해제합니다.

## 5. 공지

숨김 메뉴의 공지를 열면 목록만 표시됩니다. 읽지 않은 공지가 구분되고 메뉴 배지에 개수가 표시됩니다. 항목을 누르면 공지 상세페이지로 이동합니다. 전체 본문과 등록 시간을 읽을 수 있고 진입 시 읽음 상태를 저장합니다. 상단 뒤로가기와 브라우저 뒤로가기로 목록에 돌아갑니다. 상세 주소를 새로고침해도 공지를 다시 불러옵니다. 삭제되었거나 접근할 수 없는 이전 개별 공지이면 찾을 수 없음 안내를 표시합니다. 읽음 처리 실패 메시지가 나오면 목록에서 다시 시도합니다.

## 6. 파일관리

＋를 누르고 파일을 선택해 업로드합니다. 파일 용량에 따른 앱 제한 없이 원본을 나눠 전송하며 업로드 진행률을 표시합니다. 실패하면 선택한 파일을 유지하므로 다시 업로드할 수 있습니다. 큰 파일의 다운로드에는 기기 메모리와 저장소 여유 공간이 필요합니다. 목록에는 파일명과 등록일을 표시하며 파일명을 누르면 다운로드합니다. 삭제는 권한이 있을 때 표시됩니다. 작업 권한이 없으면 해당 버튼이나 메뉴가 보이지 않을 수 있습니다.

## 메모 사용

숨김 메뉴의 메모를 엽니다. 상단 ＋로 새 메모를 만들고 제목과 내용을 작성한 뒤 저장합니다. 카드를 선택하면 저장한 메모를 다시 열 수 있습니다. T에서 글꼴과 서식을 선택하고 사진으로 PNG/JPG/WebP를 첨부합니다. 그리기에서 펜 색상·굵기를 선택해 그린 뒤 메모에 넣기를 누릅니다. 마이크는 첫 사용 시 권한을 허용하고 다시 누르면 녹음이 종료되어 재생 가능한 음성이 첨부됩니다. 녹음 종료 후 저장하세요.

↶·↷ 또는 Ctrl/Cmd+Z·Shift+Z로 제목·내용·서식·첨부 변경을 되돌립니다. …에서는 색상, 고정, 검색, 폴더 이동, 텍스트 공유/내보내기, 복제, 정보, 삭제를 선택합니다. 별은 중요 표시입니다. 폴더 이동과 고정·색상·별 변경은 저장 버튼으로 확정합니다. 복제는 저장해야 새 항목이 만들어집니다. 목록 검색은 제목·내용, 필터는 중요·폴더, 정렬은 최근 수정·제목·오래된 순입니다.

마이크는 음성 녹음이며 자동 받아쓰기가 아닙니다. 브라우저 지원·HTTPS 및 사용자의 마이크 권한이 필요합니다. 메모 사진은 원본 파일 용량으로 차단하지 않으며 필요하면 최대 1920px 범위로 크기·용량을 줄여 저장합니다. 원본 보관은 파일 관리 업로드를 이용하세요. 메모 전체 저장 데이터 3MB, 음성 첨부 한 개 2MB, 첨부 최대 20개는 유지됩니다. 메모 삭제는 복구할 수 없습니다. 관리자 권한 설정에서 메모 조회·등록·수정·삭제를 각각 조정할 수 있습니다.

## 관리자 첫 설정

관리 권한이 있는 사용자만 숨김 메뉴의 관리자를 사용할 수 있습니다. 관리자 화면도 같은 헤더를 사용합니다. 숨김 메뉴 상단의 업무일지로 돌아가기로 사용자 화면에 돌아갑니다.

1. 사용자 설정에서 신규 가입을 승인·반려합니다. ＋로 직접 사용자도 등록할 수 있습니다.
2. 권한 설정에서 일반 사용자의 기본 기능과 관리 기능을 각각 설정합니다. 일반 사용자가 필요한 일부 관리 기능만 받을 수도 있습니다. 활성 관리자는 최소 한 명을 유지합니다.
3. 공지 관리 ＋에서 공통 게시글의 제목과 내용을 입력합니다. 목록 수정은 같은 팝업이며 기존 값이 채워집니다. 오류가 나면 입력을 유지한 채 수정하고 다시 저장합니다.
4. 파일 관리 ＋로 등록합니다. 파일관리 권한과 개인 업로드 권한이 함께 필요합니다. 전체 파일 이름 변경·다운로드·삭제를 사용할 수 있습니다.
5. 화면·배경 설정은 폰트·크기·간격·색상·로그인 배경을 미리 보고 저장하여 전체 사용자에게 적용합니다. 배경은 PNG/JPG/WebP 최대 1MB입니다.

## 자주 생기는 상황

- 메뉴·버튼이 안 보임: 관리자에게 해당 기본 또는 관리 권한을 확인해 달라고 요청합니다.
- 로그인 거부: 승인 대기·반려·비활성 여부, 비밀번호를 확인합니다.
- 작업 중 로그인 화면 이동: 세션이 만료되었을 수 있습니다. 다시 로그인합니다.
- 파일이 등록되지 않음: 업로드 권한, 네트워크 연결과 저장소 여유 공간을 확인하고 다시 업로드합니다.
- 저장소 연결 오류: 운영 담당자에게 알립니다. 화면에서 반복 저장하지 않습니다.

개발 환경 설정은 [개발자 온보딩](ONBOARDING-DEVELOPER.md)을 참고하세요.

## 공지사항 기능 (2026-10-01)

이 메뉴는 사이트 내 공지 게시판입니다. 푸시 알림·브라우저 알림 권한·백그라운드 발송을 사용하지 않습니다. 사용자 메뉴는 **공지사항**, 관리자 메뉴는 **공지 관리**입니다. 숫자 배지는 미열람 공지 수입니다. 사용자 목록에서 제목을 누르면 상세페이지로 이동하고 열람 처리합니다. 기존 제목 없는 공지는 내용을 목록 제목으로 표시합니다.

관리자는 ＋ 팝업에서 제목(선택, 최대 120자)과 내용(필수, 최대 2000자)을 작성합니다. 공지는 모든 승인된 사용자가 함께 보는 게시글 한 건이며 이후 가입자도 조회합니다. 관리자 목록도 게시글당 한 번만 표시하고 열람 인원/전체 인원을 보여 줍니다. 제목·내용 검색과 열람/미열람 사용자 있음 필터를 제공합니다. 공통 글 수정·삭제는 전체에 적용하며 수정하면 사용자별 읽음을 초기화합니다. 기존 업데이트 공지 복사본은 releaseId로 연결하고 이전 읽음·상세 URL을 유지합니다. 이전 개별 공지는 원래 게시 대상만 조회하며 동일 시각·제목·내용의 과거 일괄 게시 기록은 관리자 목록에서 묶어 관리합니다.

호환성을 위해 API `/api/notifications`, `/api/admin/notifications`, 상세 URL `#notifications/ID`, 저장소 `notifications`, 권한 키 `notifications`·`notificationRead`를 유지합니다. 이 내부 이름으로 푸시 기능을 추가하지 마세요. 관리자 등록은 `title`, `message`로 공통 글 한 건을 만들고 `id`, `count: 1`, `ids`를 반환합니다. 이전 클라이언트의 userId는 신규 대상 선택에 사용하지 않습니다. 수정·삭제는 게시글 ID에 적용합니다. API와 실제 브라우저 하네스에서 대상·소유권·입력 검증·필터를 확인합니다.


## TODO 직접 수정과 전체 내용 검색

TODO 직접 수정의 입력칸 오른쪽 ＋ 팝업에서 같은 단계·하위 항목을 추가하고 상위로·하위로 이동을 예약한 뒤 저장합니다. 취소는 모든 변경을 버리며 실패하면 입력을 유지합니다. 완료 상태와 기존 자식 항목은 보존하고 새 항목은 미완료입니다. Enter는 현재 항목 안 줄바꿈, Ctrl/⌘+Enter는 저장입니다. 전체 수정창은 한 줄마다 새 항목이며 기존 항목 안 줄바꿈은 `\ ` 접두사로 유지합니다.

일일리스트 돋보기 팝업의 전체 내용 검색은 날짜 조건을 해제하고 본인 일지 전체의 TODO·익일 계획·비고·메모·업무일자를 검색합니다. 결과를 노란색으로 강조하고 ↑ 이전 / ↓ 다음으로 이동합니다. 현재 결과는 진한 색으로 표시하며 접힌 카드도 펼쳐 주변 내용을 확인합니다. 검색 해제는 원문을 복구합니다. HTML을 해석하지 않고 텍스트 노드와 mark만 생성하며 저장 내용은 바꾸지 않습니다. 검색 중 TODO 직접 수정은 마친 후 사용합니다.
## 계정 메뉴와 비밀번호 화면

계정 기능은 좌측 메뉴 하단의 관리자·자물쇠·로그아웃 아이콘을 사용하세요. 비밀번호 화면의 X 또는 Escape로 이전 메뉴로 돌아갑니다. 임시 비밀번호 사용자에게는 변경이 필수이며 X를 누르면 로그아웃합니다.

## 메모 편집·자동 저장 (2026-10-01)

저장 버튼 없이 입력을 650ms 멈추면 자동 저장합니다. 닫기는 남은 변경 저장 후 목록으로 돌아가고, 실패 시 내용을 유지하며 다시 저장 버튼을 제공합니다. 한글 조합 중에는 저장을 미루고 완료 뒤 저장합니다. 요청은 직렬화하며 저장 응답은 현재 입력을 덮어쓰지 않습니다. 실행 취소·다시 실행은 상단에, 편집 도구는 키보드 위에 표시합니다. 모바일 편집기는 VisualViewport 높이와 offsetTop을 반영하며 더보기 메뉴는 화면 안에서 스크롤합니다. 외부 에디터·아이콘 플러그인 없이 로컬 SVG를 사용합니다.

검증: scripts/verify-memos.cjs에서 자동 저장·재열기·저장 중 입력·실패/재시도·서식/그리기/녹음·PC/모바일을 확인합니다. 키보드 화면 크기는 VisualViewport 축소 시뮬레이션으로 확인했으며 실제 iPhone 키보드의 최종 호환성은 기기 확인이 필요합니다.
공지 관리 검색은 우측 상단 돋보기 → 검색 팝업(검색어·열람 상태) → 조회로 적용합니다. 전체는 조건을 초기화하며, 취소·닫기·Escape는 기존 조건을 유지합니다. 본문에 상시 검색 폼을 두지 않습니다. ＋ 등록은 돋보기 옆에 유지합니다.

## 공통 검색 레이아웃

메모 검색은 본문 입력창이 아니라 헤더 우측 돋보기(＋ 왼쪽) → 검색 팝업입니다. 팝업에서 제목·내용 검색어, 전체·중요·폴더 분류, 정렬을 지정하고 검색으로 적용합니다. 닫기·Escape는 적용하지 않은 입력을 버리며 다시 열면 마지막 적용 조건을 보여 줍니다. 전체 보기는 조건과 정렬을 초기화합니다. UIConfig는 검색 액션과 권한·팝업 ID를 선언하고 UIShell.searchDialog는 열기·적용·취소·초기화 동작을 공통으로 제공합니다. 새 검색 메뉴는 이 모듈을 재사용하고 본문 상시 검색 폼을 추가하지 않습니다. 디자인 하네스의 메모 메뉴에서도 같은 모듈로 검색·전체 보기·취소와 검색 버튼 우측 배치를 검증합니다.


메모 조회 시 하단 편집 도구·서식 패널은 숨겨 공간을 차지하지 않습니다. 제목·본문을 눌러 편집하면 도구를 표시하고, 키보드 내리기 또는 편집 영역 밖으로 이동하면 숨깁니다. 기존 메모를 열 때는 자동으로 키보드를 띄우지 않습니다. 새 메모는 제목 입력으로 시작합니다.

메모 카드 우측 체크박스로 여러 메모를 선택하고 **선택 삭제**를 누릅니다. 전체 선택은 현재 검색·분류 결과에만 적용되며 삭제 전 선택 개수를 확인합니다. 취소하면 선택을 유지하고, 일부 삭제가 실패하면 실패한 메모만 선택을 유지해 재시도할 수 있습니다. 삭제 권한이 없는 사용자는 선택·삭제 버튼을 볼 수 없습니다. 빈 첨부가 객체로 저장된 기존 메모도 정상적으로 열립니다.

메모 목록 상단의 전체 선택·선택 개수·선택 삭제·선택 해제 도구는 카드 체크박스로 메모를 하나 이상 선택했을 때만 표시됩니다. 모두 해제하거나 선택한 메모를 삭제하면 숨겨집니다.


## 사진·파일에서 텍스트 불러오기

일지 등록·수정 팝업의 TODO·익일 계획·메모 입력칸 아래의 한 줄 도구에서 **항목 추가**를 누르면 **직접 항목 추가 / 사진에서 불러오기 / 파일에서 불러오기** 선택 팝업이 열립니다. 파일 선택 → 텍스트 읽기 → 미리보기 수정 → 기존 내용 뒤에 추가 또는 전체 교체 → 에디터에 넣기 순서입니다. 넣기 전에는 기존 내용을 바꾸지 않으며, 취소·Escape는 가져오기만 닫습니다. 일지는 기존 등록·수정 버튼으로 저장합니다.

지원: PNG/JPEG/WebP/BMP 사진, XLSX/XLS/ODS/CSV/TSV, TXT/MD/LOG/JSON/XML/HTML, DOCX, 텍스트 PDF. 엑셀은 시트와 모든 열/특정 열을 선택하며 셀의 표시 문자열을 읽습니다. 매크로·수식을 실행하지 않습니다. 텍스트는 UTF-8/UTF-16/CP949 자동 인식 또는 직접 선택합니다. 줄바꿈을 유지하고 엑셀 열 사이는 공백으로 구분합니다. TODO·익일 계획에서는 한 줄마다 새 항목입니다. 문서 서식·표 구조를 그대로 재현하는 기능은 아니며 사진·PDF의 읽기 순서는 원본과 다를 수 있습니다.

사진 OCR은 인쇄 글자·스크린샷에 적합하며 손글씨·흐릿한 사진은 오인식될 수 있습니다. 한국어+영어 또는 언어 하나를 선택할 수 있습니다. 작은 사진은 크기를 보정하고 낮은 품질이면 대비·배치를 바꿔 한 번 더 읽습니다. 사진 글자 배치(자동/한 열/흩어진 글자)와 방향을 선택할 수 있으며 품질이 낮으면 경고를 표시합니다. 경고가 없어도 원본과 비교해 확인하세요. 스캔 PDF는 텍스트 추출 대상이 아니며 페이지를 사진으로 저장해 사진 불러오기를 사용합니다. 암호화 문서는 해제한 파일을 사용하세요. HWP/DOC/HEIC는 지원하지 않습니다.

추출은 브라우저 안에서 수행하며 원본 파일을 서버나 외부 서비스에 업로드하지 않습니다. 모든 처리 파일을 사이트의 `public/vendor/`에 포함하므로 인터넷·별도 프로그램 설치가 필요 없습니다. 기존 로컬 웹서버는 실행해야 합니다. 처음 사진 불러오기에는 엔진 로딩 시간이 필요하며 큰 파일은 기기 메모리와 처리 시간을 사용합니다.

사진 불러오기의 기본 가져올 내용은 **본문 글자만**입니다. 알아볼 수 있는 표 선·체크박스 기호를 정리하며 영문·숫자·문장부호는 유지합니다. **인식 원문 그대로**로 전환해 원래 결과를 확인할 수 있으며 방식별 수정 내용을 보존합니다. 선을 J·I처럼 실제 문자로 잘못 읽은 경우에는 본문과 구분할 수 없어 자동 삭제하지 않으므로 직접 수정해 주세요. 이 정리는 사진 OCR 결과에만 적용하며 엑셀·텍스트 파일의 내용은 유지합니다.

## 보고서 참조·링크 및 자식 이동

보고서 등록·수정의 TODO·익일 계획·비고·메모와 TODO 직접 수정에서 @를 입력하면 접근 가능한 파일·메모·일지(일정)를 검색합니다. 종류별 필터와 제목·내용 검색, ↑↓·Enter 선택, Escape 취소를 제공합니다. 이메일 주소 안의 @는 열지 않으며 한글 조합 중 Enter는 선택하지 않습니다. #는 표시 이름과 http:// 또는 https:// 주소를 입력하는 링크 팝업입니다. 취소하면 기존 문자를 유지합니다.

참조는 입력 중 저장 표기로 보이며 조회 목록에서는 대상 이름의 링크로 표시됩니다. 링크를 한 번 클릭하면 내용을 조회합니다. 이미지 파일은 현재 일정 위의 미리보기 팝업으로 열리고, 이미지를 누르면 전체 화면으로 확대됩니다. 전체 화면에서 원본 크기·화면에 맞추기를 전환할 수 있습니다. 닫기·Escape·브라우저 뒤로가기는 확대 → 미리보기 → 원래 일정 순서로 돌아갑니다. 메모·일지·일반 파일 참조 상세의 상단 뒤로가기와 브라우저 뒤로가기도 참조를 연 일정으로 복귀하며 기존 검색·필터와 스크롤 위치를 유지합니다. 상세를 새로고침해도 복귀 경로를 유지합니다. 메모 참조의 첨부 이미지도 클릭하여 크게 봅니다. 내부 참조는 고유 ID로 연결하여 대상 이름이 변경되어도 유지합니다. 표시 이름은 삽입 시 이름을 보존합니다. 삭제·접근 권한 없음은 안내를 표시하며 보고서 원문은 유지합니다. 파일 참조는 정보와 다운로드 버튼, 메모 참조는 본문·첨부, 일지 참조는 전체 내용을 보여 줍니다. 외부 링크는 새 탭으로 연결합니다.

TODO 일반 본문은 더블클릭·두 번 탭·Enter/F2로 편집하며 링크 클릭은 편집을 시작하지 않습니다. 모바일에서는 TODO 일반 문구를 빠르게 두 번 탭하세요. 직접 수정 입력칸 오른쪽 44px ＋ 팝업에서 같은 단계 추가·하위 항목 추가를 선택합니다. 팝업 Escape는 팝업만 닫고 수정 중 내용은 유지합니다. 리스트 직접 수정의 상위로·하위로 버튼은 없으며, 오른쪽 점 손잡이를 드래그해 다른 항목의 위·아래로 옮깁니다. 대상 항목과 같은 단계로 이동하고 자식·손자는 함께 유지됩니다. 자식 안으로 부모를 넣거나 다른 일지로 이동할 수 없습니다. 저장 실패 시 기존 위치를 유지합니다. 손잡이에 포커스 후 Alt+↑/↓로도 같은 단계 순서를 바꿀 수 있습니다. 등록·전체 수정 입력창의 단계 변경과 Tab/Shift+Tab도 자식을 함께 이동합니다. 기존 완료 상태·항목 안 줄바꿈은 유지합니다.

드래그 중에는 부모·자식 미리보기가 포인터를 따라 움직이고 놓을 위치에 빈칸이 표시됩니다. 항목 사이 여백에도 놓을 수 있으며 다른 일지에는 이동하지 않습니다. 손잡이는 28px, 단일 줄 항목은 약 40px 높이로 체크박스·본문을 가운데 정렬합니다. ＋ 선택 팝업의 바깥을 누르면 팝업만 닫고 입력을 유지합니다.

## 캘린더

좌측 메뉴 → 캘린더에서 월간·주간·일간을 선택합니다. ＋로 기간·시간·종일 일정과 휴무·휴가를 등록합니다. 날짜를 누르면 일정·투두·메모·파일을 확인하고 기존 상세로 이동합니다. 일정 막대를 누르면 수정·삭제 팝업입니다. 알림은 로그인한 앱을 열어 둔 동안 동작하며 기기 알림 허용은 선택입니다. [자세한 사용법과 범위](CALENDAR.md).
일지 카드의 TODO·익일 계획·비고·메모 제목 오른쪽 ＋로 해당 영역만 등록합니다. 빈 영역에서도 사용할 수 있고 줄바꿈마다 새 항목입니다. 각 줄을 더블클릭·두 번 탭하면 수정하며 입력칸 ＋에서 같은 단계·하위 항목을 추가합니다. TODO·익일 계획은 체크박스로 완료 처리하고 비고·메모는 점(•)으로 표시하며 취소선을 넣지 않습니다. 오른쪽 점 손잡이로 자식과 함께 이동합니다. 비고도 메모처럼 여러 줄을 입력합니다. 취소·실패 시 입력과 기존 내용은 유지됩니다.

캘린더 상단 액션은 돋보기(조회 팝업)·…(기기 알림/새로고침/표시 항목)·＋(등록)입니다. 제목 양옆 기간 화살표, 월·주·일 전환, 달력 하단 오늘 버튼과 짧은 월간 행을 사용합니다. 검색은 UIShell.searchDialog를 재사용하며 취소 시 적용 조건을 유지합니다. CalendarCore.tasks는 Redis 빈 객체와 중첩 하위 항목을 정규화합니다.

캘린더 날짜별 목록은 종류별 건수와 제목 링크만 표시합니다. 투두·일지 메모·메모 본문·일정 설명은 상세에서 확인하며 긴 제목은 한 줄 말줄임합니다. 스케줄은 제목·시간만 표시하고 누르면 일정 팝업을 엽니다. 자료 링크를 본 뒤 닫기·뒤로가기로 원래 캘린더에 돌아옵니다.

## Windows 로컬 포터블 실행·바로가기
