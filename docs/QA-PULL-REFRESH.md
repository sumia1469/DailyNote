# 공통 당겨서 새로고침 검증

2026-10-02. 운영 자료를 사용하지 않는 로컬 예시 계정·저장소에서 검증했습니다.

- `npm test`: 53개 통과.
- `npm run test:ui`: 7개 통과.
- `npm run test:pull-refresh`: PC 1440×1000, 모바일 390×844에서 사용자 6개 메뉴·게시판 목록/상세·관리자 6개 메뉴 조회. 짧은 당기기·가로 이동·여러 손가락·터치 취소·목록 중간·작성 중 차단, 중복 요청 방지, 실패/재시도, 날짜 검색 유지, 이동 후 이전 응답 무시, 관리자 미저장 설정 보존과 저장 후 잠금 해제 통과. CDP의 실제 모바일 터치 이벤트로 새로고침 요청 발생 확인. 페이지 JS 오류 없음.
- `npm run test:common-loading`: 사용자/관리자 메뉴, 동시 요청·응답 본문·오류·취소·조용한 폴링 통과.
- `npm run test:writing`: 모든 등록 페이지·뒤로가기·관리 CRUD·저장 중 이동·메모 실패 입력 유지 통과.
- `npm run test:boards`: 분류·키보드·검색·에디터·캐시/오래된 응답·첨부/코드/참조·상세 URL·엑셀·PC/모바일 배치 통과. 첫 병렬 실행에서는 초기 분류 탭 대기 시간이 초과했으며 별도 재실행과 진단 실행은 통과했습니다.

제품 프런트엔드에는 라이브러리를 추가하지 않습니다. 브라우저 테스트에만 개발용 Playwright를 사용합니다. 실행 환경에 따라 `PLAYWRIGHT_MODULE_PATH`, `BROWSER_EXECUTABLE_PATH`를 지정할 수 있습니다. iOS Safari 및 설치형 PWA 실기기 제스처 검증은 별도 확인 대상입니다. 운영 배포는 이 로컬 검증과 별개입니다.
