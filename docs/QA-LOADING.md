# 로딩 모션 검증

- 기본: 7번 꽃잎 순환. 10가지 모션은 관리자 화면·배경 설정에서 미리보기 후 저장.
- `npm test`: API에서 전체 모션 저장·공개 설정 조회·기존 화면 설정 보존·일반 사용자 권한 거부·잘못된 모션 거부를 확인.
- `npm run test:ui`: 공통 화면 계약 검증.
- `npm run test:loading`: 격리된 JSON 데이터로 PC 1440×1000, 모바일 390×844에서 10개 모션의 시간별 변화, 저장·새로고침, 사용자 화면 반영, 투명 패널, 로고 로드, 가로 넘침 없음, 다크 반전, 동작 줄이기를 확인.
- 운영 Redis와 실제 사용자 자료를 사용하지 않으며 프런트엔드 외부 요청이 없음을 확인.
- CSS 모션만 사용하고 요청별 동시 처리·완료 시 닫기 흐름은 기존 사용자·관리자 모듈을 유지.

기존 로그인·폼·권한·메뉴·공지의 공통 브라우저 검증도 실행합니다. 저장된 설정은 다음 화면 진입 시 다시 조회합니다. 다른 사용자에게 열려 있는 기존 화면을 실시간으로 변경하는 기능은 포함하지 않습니다.
