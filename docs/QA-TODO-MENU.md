# TODO 항목 메뉴 검증

## 구현
- TODO·익일 계획·비고·메모의 … 및 우클릭 메뉴: 수정·복제·삭제
- 체크 가능한 두 영역은 완료/미완료 전환 추가
- 같은 단계에 하위 트리·체크 상태·줄바꿈·참조를 깊은 복사
- 하위 항목 수를 포함한 삭제 확인, 취소·실패 후 재시도
- 수정 권한과 기존 서버 소유권 검증 유지
- 공통 드롭다운의 화면 경계·키보드·바깥 클릭·스크롤 닫기 재사용
- 재렌더로 사라진 행의 메뉴 닫기 및 오래된 액션 차단

## 실행 결과
- `npm test`: 60/60 통과
- `npm run test:ui`: 7/7 통과
- 선택 개발 도구 JSDOM을 사용한 `scripts/verify-todo-menu-dom.cjs`: 복제 독립성, 완료 상태, 수정 호출, 삭제 취소/실패/재시도, 복제 실패/재시도, 오래된 행, 링크 기본 우클릭, 편집 잠금, 중복 제출 통과
- JSDOM은 렌더링/실제 브라우저 검증을 대체하지 않습니다. `JSDOM_MODULE_PATH`로 개발 환경의 설치 경로를 지정할 수 있습니다. 런타임 의존성에는 추가하지 않았습니다.
- `npm run test:todo-menu`: 브라우저 자동화 시나리오 작성. 실행 환경의 Chromium이 `socket() failed: Operation not permitted`로 시작하지 못해 PC·모바일 실제 화면은 미검증입니다.
- 프런트엔드 빌드·별도 lint 스크립트는 없는 바닐라 JS 프로젝트입니다. 수정한 JavaScript 구문 검사 통과.

## 추가 확인
실제 브라우저에서 1440×1000·390×844, 화면 하단 메뉴, 터치 …, 키보드, 삭제 취소/재시도와 저장 후 포커스를 확인해야 합니다. `/design-harness.html`의 네 영역 예시는 운영 API를 호출하지 않는 메모리 내 데이터입니다.
