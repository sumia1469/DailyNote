# 하단 설정·본인 프로필 검증

2026-10-02: 최신 공통 로딩 변경을 포함한 설정 드롭다운·작은 계정 버튼 구현으로 예시 계정과 임시 JSON 저장소를 사용했습니다. 운영 자료를 변경하지 않았습니다.

- 전체 Node 기능 테스트 47개·UI 계약 테스트 7개 통과.
- Chromium 실제 브라우저: PC 1440×1000, 모바일 390×844 통과.
- 프로필 사진 업로드·미리보기·저장·삭제, 별명 저장·취소, 저장 실패 입력 유지, 재접속 복원 확인. 사용자·관리자 화면에서 공통 편집기 확인.
- 설정 드롭다운 메뉴의 시작하기·바로가기·비밀번호·관리자·로그아웃 표시, 일반 사용자 관리자 숨김 확인.
- 사용자·관리자 드롭다운 로그아웃 확인. 설정 Escape는 작은 메뉴만 닫고 숨김 메뉴를 유지. 비밀번호 X·Escape 복귀와 필수 변경 닫기 시 로그아웃 확인.
- 320×568·844×390에서도 이름 오른쪽 32px 버튼·18px 아이콘 배치와 드롭다운 넘침 확인. 페이지 JS 오류 없음.
- 공지 상세·등록·수정·검색·파일 업로드·엑셀·디자인 하네스 회귀 통과.

실행: PLAYWRIGHT_MODULE_PATH 및 BROWSER_EXECUTABLE_PATH를 기존 개발용 Playwright·Chromium 실행 파일로 지정하고 node scripts/verify-ui.cjs. 개발 검증 도구는 제품 의존성에 추가하지 않습니다. 실제 iOS 기기 검증과는 구분합니다.

설정 메뉴는 role=menu, 버튼 바로 위 오른쪽 정렬, 중앙 dialog 없음, 화면 밖 넘침 없음, ↑↓·Home·End·Escape 키보드 선택을 추가 검증합니다.
