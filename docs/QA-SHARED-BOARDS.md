# 공유게시판 검증 기록

2026-10-02, 운영 Redis·사용자 계정을 사용하지 않는 임시 JSON 서버와 Chromium 하네스에서 검증했습니다.

- Node API/모듈 테스트 43개 통과, UI 계약 테스트 6개 통과.
- API: 로그인 필수, 관리 권한 거부, 모든 이용자 공통 조회, 작성자·관리자만 수정/삭제, 기본 조회 권한 거부, 분류 검증, ID 커서의 중복 없는 20+5건, 검색, 글이 있는 게시판 삭제 거부·비활성화·이름 변경.
- 첨부·참조: 남의 개인 파일/메모 ID 거부, 개인 URL의 소유권 유지, 실제 게시글 첨부 경로만 공유 다운로드, 원문 삭제 후 복제된 글의 첨부 유지, 다운로드 권한 거부, 메모 변경 내용이 참조 사본에 추가 노출되지 않음.
- 실제 UI 1440×1000·390×844: 관리 ＋로 게시판 생성과 메뉴 연결, 코드 블록·기본 하이라이트, 이미지 첨부·본문 표시·확대, 손그림 첨부, 메모 참조·사용자 멘션, 복제, 직접 URL·새로고침·뒤로가기, 검색·검색 결과 XLSX 다운로드, 저장 503 실패 후 입력 유지·재시도, 20건부터 스크롤 40건 추가 조회, 악성 HTML 실행·이벤트 속성 제거, 삭제된 글 오류, 중앙 제목·팝업 폭·가로 넘침 없음·페이지 JS 오류 없음.
- XLSX: 7개 열·필터·헤더 병합 없음·수식처럼 보이는 텍스트를 수식으로 실행하지 않음.
- 기존 공통 브라우저 하네스(PC·모바일 22개 캡처·중앙 제목·공지 상세·저장 실패·파일 업로드·권한·계정 메뉴)와 공지 페이징 하네스(400건·최초 30건·스크롤 추가·미로드 데이터 검색·조건 초기화·비활성 API 호출 생략)도 통과했습니다.

실제 iOS Safari의 시스템 글꼴, 키보드, 파일 선택·공유 패널은 Chromium 에뮬레이션 검증과 별개입니다. 코드 하이라이트는 외부 파서 없이 기본 토큰을 색칠하며 언어별 전체 문법 분석은 제공하지 않습니다.
