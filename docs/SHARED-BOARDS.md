# 동적 공유게시판

관리페이지의 **게시판 관리 → ＋**에서 이름, 게시판 그룹, 설명, 글 분류, 메뉴 순서, 메뉴 노출, 활성 여부를 저장합니다. 메뉴에 표시한 활성 게시판은 사용자 숨김 메뉴에 그룹별로 나타납니다. 메뉴를 숨겨도 공유게시판 목록에서 접근할 수 있습니다. 비활성화하면 글을 보존하고 사용자 조회를 중지합니다. 글이 없는 게시판만 삭제할 수 있습니다.

## 사용자 동작

- 공유게시판에서 게시판을 선택합니다. 공지와 같은 목록 형태로 제목, 내용 요약, 분류, 작성자, 등록일, 태그, 첨부 수를 표시합니다.
- 상단 **돋보기**에서 제목·본문·작성자·태그와 분류를 조회합니다. 취소는 기존 조건을 유지하고 전체 보기는 초기화합니다. 게시판별 검색 조건을 유지합니다.
- **＋**로 글 작성 팝업을 엽니다. 제목·분류·본문을 작성하고 게시합니다. 저장 실패 시 입력을 유지하고 중복 제출을 차단합니다.
- 편집 도구: 운영체제 고딕·명조·고정폭, 굵게·기울임·밑줄, 번호·글머리 목록, 코드 블록, 파일, 본문 이미지, 손그림, 메모·일지·파일 참조, # 태그, @ 사용자 멘션.
- 코드 추가에서 언어를 선택하고 원문을 붙여 넣습니다. 상세는 안전하게 텍스트를 표시하고 기본 문법 색상과 코드 복사를 제공합니다. 코드 실행 기능은 없습니다.
- 사진·그림은 본문 위치에 삽입됩니다. 첨부 파일은 기존 분할 업로드를 사용하며 상세에서 다운로드합니다. PNG·JPEG·WebP 이미지는 상세에서 눌러 확대합니다.
- 참조는 본인 자료만 선택합니다. 메모·일지는 선택한 시점의 내용을 복사하며 원문이 이후 변경돼도 비공개 변경 내용을 추가 노출하지 않습니다. 참조한 파일은 게시글 첨부로 공유합니다.
- # 태그는 태그 필드에서 입력하고 @ 멘션은 사용자 선택으로 추가합니다. 본문에서 @를 입력하면 멘션 선택을 열고 #는 태그 입력으로 이동합니다. 코드 블록 내부에서는 일반 문자로 입력합니다. 멘션은 글 내 표시이며 푸시·메일 발송은 없습니다.
- 글을 누르면 `/#boards/게시판ID/posts/글ID` 상세로 이동합니다. 직접 URL·새로고침·뒤로가기를 지원하며 목록 복귀 때 불러온 글과 스크롤을 유지합니다.
- 상세 **…**에서 수정·삭제·복제·공유·내용 복사를 제공합니다. 수정·삭제는 해당 기본 권한을 가진 작성자 또는 게시판 관리자만 가능합니다. 복제는 작성 권한이 있으면 새 글로 게시합니다.
- 목록 **… → 엑셀 다운로드**는 현재 검색 조건의 전체 글을 XLSX로 내려받습니다. 제목·분류·작성자·날짜·태그·본문 텍스트를 포함합니다. 긴 본문은 여러 행으로 나눠 보존합니다. 이미지 원본은 첨부 다운로드를 사용합니다.
- 목록은 20건부터 표시하고 스크롤 하단에서 추가 조회합니다. 추가 로딩 버튼도 제공합니다. 응답은 본문 HTML·첨부 데이터 없이 요약만 전달합니다.

## 권한과 데이터

`boards`는 게시판 관리 권한입니다. 기본 사용자 권한은 `boardRead`, `boardCreate`, `boardEdit`, `boardDelete`이며 기존 계정의 미설정 기본 권한은 켜집니다. 서버가 매 요청에서 검증합니다. 게시판은 모든 승인된 로그인 사용자가 공유하며 게시판별 회원 지정은 제공하지 않습니다. 다운로드에는 `fileDownload`, 업로드에는 `fileUpload`, 참조에는 해당 자료 조회 권한이 필요합니다. 개인 파일 URL은 기존 소유권을 유지하고 게시글 첨부 경로에서만 공유 다운로드를 허용합니다.

저장소는 `boards`, `board_posts`를 추가합니다. 기존 메모·공지·일지 데이터는 변경하지 않습니다. JSON과 Redis를 지원하며 Redis Lua 갱신으로 빈 배열이 객체가 된 경우에도 조회에서 정규화합니다.

| 경로 | 역할 |
| --- | --- |
| `/api/admin/boards`, `/:id` | 관리자 목록·등록·설정·빈 게시판 삭제 |
| `/api/boards`, `/:id` | 활성 게시판 목록·상세 |
| `/api/boards/:id/members` | 멘션 대상 활성·승인 사용자 |
| `/api/boards/:id/posts` | 글 등록, 검색·분류·ID 커서 페이징 |
| `/api/boards/:id/posts/:postId` | 글 조회·수정·삭제 |
| `/api/boards/:id/posts/:postId/files/:fileId` | 게시글에 실제 첨부된 파일 다운로드 |

## 모듈과 검증

`src/board.routes.js`는 공유 권한·참조·첨부 검증과 API를 담당합니다. `public/boards.js`는 공통 `UIShell.searchDialog`, `AppShell`, `ListScroll`, `FileTransfer`, `WorklogExcel`에 연결합니다. `public/board-admin.js`는 공통 관리자 셸에 연결합니다. 프런트엔드 런타임 패키지·CDN·외부 글꼴을 추가하지 않습니다. 현재 데이터 저장소는 서버에서 전체 글을 읽고 필터링하므로, 대규모 게시판은 저장소 인덱스를 별도로 도입해야 합니다.

`npm test`, `npm run test:ui`, 개발용 Playwright가 준비된 환경에서 `npm run test:boards`로 검증합니다. 운영 계정이나 Redis 데이터 없이 임시 JSON·첨부 디렉터리를 사용합니다. 공유 조회·권한 거부·첨부 경로 제한·참조 복사·복제·분류·ID 커서와 실제 PC/모바일 작성·코드·그림·이미지·검색·엑셀·오류 입력 유지·직접 URL·새로고침·뒤로가기·가로 넘침·HTML 실행 차단을 확인합니다.


## 게시판 … 메뉴

게시판 목록·상세의 …는 일지 카드와 같은 작은 아이콘 메뉴로 열립니다. 중앙 제목·닫기 버튼·둥근 개별 버튼 대신 … 아래에 기능을 한 줄씩 표시하고, 삭제는 구분선과 빨간색으로 표시합니다. 바깥 클릭·Escape로 닫으며 ↑↓·Home·End로 이동합니다. 메뉴는 화면을 벗어나지 않도록 위치를 보정합니다. 기존 엑셀 다운로드·공유·새로고침·관리 및 상세 수정·복제·내용 복사·삭제와 권한 조건을 유지합니다.
## 게시판 관리 목록 메뉴

게시판 이름 아래에 그룹·활성 상태·메뉴 표시 여부, 분류와 설명을 세로로 표시합니다. 우측 … 버튼을 누르면 설정·게시판 열기·삭제를 선택하는 팝업이 열립니다. 삭제는 별도 확인 팝업에서 실행하며 빈 게시판만 삭제합니다. 게시글이 있는 경우 오류 안내를 표시하고 게시판과 글을 보존합니다. Escape·닫기·팝업 바깥 클릭으로 취소할 수 있습니다. 삭제 요청 중에는 닫기와 중복 실행을 막습니다.



## 공통 작성 화면 (2026-10-02)

메모·게시판 글·공지·업무일지·캘린더 일정의 등록과 수정은 PC와 모바일 모두 화면 전체를 쓰는 메모 스타일입니다. 상단에는 목록으로 돌아가기, 실행 취소·다시 실행, 중앙 제목, 우측 저장/게시가 있습니다. 메모는 기존 자동 저장을 유지하고 공유되는 게시판·공지는 저장/게시 시 반영됩니다. 검색·삭제 확인·파일 선택·게시판 설정은 기존 보조 창을 유지합니다.

`writing-forms.js`와 `writing-forms.css`가 작성 화면의 공통 구조·뷰포트·상단 도구·입력 이력을 담당합니다. 업무 모듈은 기존 폼 ID, 저장 API, 검증, 권한, 첨부 및 실패 시 입력 유지 로직을 그대로 사용합니다. 새 작성 폼은 `WritingForms.register()`로 연결합니다. 모바일 키보드 크기에 맞추어 높이를 조절하고 본문만 스크롤합니다. 게시판의 서식·코드·이미지·그림·참조·멘션 도구는 편집 중 표시하고 실행 취소/다시 실행은 상단에 둡니다.

게시판 관리·게시판 상세·일지의 … 동작은 `UIShell.actionMenu()`를 공유합니다. 버튼 가까이에 작은 메뉴를 띄우며 큰 제목, 닫기 버튼, 배경 흐림을 사용하지 않습니다. 화면 밖 클릭/Escape로 닫고 키보드 방향키·Home·End와 닫은 후 버튼 포커스 복귀를 지원합니다.

검증: `npm test`, `npm run test:ui`, `npm run test:writing`, `npm run test:boards`. 실제 UI 검증은 운영 자료를 사용하지 않는 예시 계정으로 1440×1000과 390×844에서 수행합니다.


## 게시판 분류 탭

게시판 목록 상단에서 전체·등록된 분류·미분류를 둥근 탭으로 선택합니다. 선택한 탭은 연한 회색 배경과 진한 글자로 표시하며 모바일에서는 탭 줄을 좌우로 스크롤합니다. 검색어는 분류를 바꿔도 유지하고, 상세에서 돌아오면 선택한 분류와 목록을 복원합니다. 검색 팝업에서도 같은 탭을 사용하며 취소는 변경을 버리고 전체 보기는 검색어와 분류를 초기화합니다.

글 작성 분류도 같은 탭을 사용합니다. 선택한 목록 분류가 새 글의 기본 분류가 되며 수정·복제에서는 기존 글의 분류를 유지합니다. 전체는 작성 분류에 없습니다. 미분류는 분류가 지정되지 않은 글입니다. 탭에 포커스 후 방향키·Home·End로 선택하거나 Enter·Space로 누를 수 있습니다.
