DailyNote

오늘의 업무를 기록하고 내일을 준비하세요

왼쪽 메뉴로 화면을 바꾸고, 가운데 제목으로 현재 위치를 확인합니다. 오른쪽 ＋는 새 항목을 등록하는 팝업입니다.

사용자 안내 · 관리자 안내 · 개발자 안내 · 디자인 하네스

사용자 첫 업무

  1. 등록신청 후 관리자 승인을 받고 로그인합니다.
  2. 일일리스트 ＋에서 업무일자와 TODO를 한 줄씩 입력합니다.
  3. 체크박스로 완료하고 문구를 눌러 바로 수정합니다.
  4. 카드 …에서 복제·수정·내용 복사·접기·삭제합니다.
  5. 돋보기에서 날짜로 조회하고 전체로 검색을 해제합니다.

파일관리 ＋에서 파일 원본을 용량 제한 없이 나눠 업로드합니다. 저장소와 기기의 여유 공간이 필요합니다. 파일명으로 다운로드하며 등록일과 삭제를 확인합니다.

공지사항은 목록 항목을 누르면 상세페이지로 이동하고 읽음 처리됩니다. 상단 뒤로가기로 목록에 돌아갑니다.

관리자 첫 설정

  1. 숨김 메뉴 관리자 → 사용자 설정에서 가입을 승인합니다.
  2. 권한 설정에서 기본 사용자 기능과 관리 기능을 나눠 설정합니다.
  3. 공지 관리 ＋에서 제목·내용·게시 대상을 작성합니다. 전체 활성 사용자에게 게시할 수 있으며 우측 상단 돋보기의 검색 팝업에서 검색·대상·열람 상태를 선택하고 조회합니다. 전체로 검색을 해제합니다. 수정도 팝업으로 열립니다.
  4. 파일 관리 ＋에서 업로드합니다. 파일관리와 업로드 권한이 필요합니다.
  5. 화면·배경 설정에서 미리 보고 저장합니다.

업무일지 복귀는 숨김 메뉴 상단입니다. 저장 오류는 팝업 안에서 확인하고 다시 시도하세요.

개발자 온보딩

Node.js 24와 npm을 준비합니다. 프런트엔드 빌드와 외부 UI 플러그인은 없습니다. .env.example은 예시이며 자동 로드되지 않습니다.

npm ci
ADMIN_USERNAME=admin ADMIN_PASSWORD='직접 지정한 비밀번호' npm run init
npm start
npm test
npm run test:ui

ui-shell.js / ui-shell.css공통 헤더·숨김 메뉴·팝업·포커스·모바일 스타일
app-shell.js / admin.js사용자 라우트·관리자 업무 동작과 API 연결
design-harness.html디자인 규칙·예시 팝업·자동 레이아웃 확인

저장소의 README → AGENTS.md → docs/DESIGN-HARNESS.md → docs/ONBOARDING-DEVELOPER.md를 순서대로 읽으세요. 새 메뉴는 UIConfig에 선언하고 기존 셸을 재사용합니다. 운영 자료·토큰을 테스트나 문서에 넣지 않습니다.

로컬은 JSON·파일, Vercel은 Redis를 사용합니다. 배포 전 환경 변수·권한·공지 상세 소유권과 실제 PC·모바일 렌더링을 확인하세요.

참조·링크와 항목 이동

보고서 입력에서 @로 파일·메모·일지 검색 후 참조를 연결하고 #로 URL 링크를 추가합니다. 조회 목록의 링크를 누르면 상세페이지로 이동합니다. TODO 수정은 일반 문구 더블클릭 또는 두 번 탭입니다.

직접 수정 입력칸 오른쪽 ＋에서 같은 단계·하위 항목을 추가합니다. 리스트 오른쪽 점 손잡이를 드래그하면 위치가 이동하고 자식도 함께 이동합니다. 다른 항목 위·아래에 놓으면 그 항목과 같은 단계가 됩니다.
