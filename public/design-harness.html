공통 디자인·동작 하네스

예시 전용 화면입니다. 운영 API를 호출하거나 자료를 저장하지 않습니다.

메뉴를 바꾸고 돋보기 검색·＋ 팝업과 숨김 메뉴를 확인하세요.

일지 예시

오늘의 업무 확인예시 데이터 · 공통 제목과 등록 위치 확인

검증할 흐름

  1. 사용자·관리자 메뉴 선택 → 중앙 제목과 ＋ 표시 확인.
  2. ＋ → 빈 입력 저장 → 오류 유지 → 입력 후 저장.
  3. 수정 → 기존 값 확인 → 저장.
  4. 숨김 메뉴 → Tab 순환 → Escape → 메뉴 버튼 포커스 복귀.
  5. 메모 선택 → 우측 돋보기 → 검색 적용·전체 보기·취소 확인.
  6. 뷰포트 PC·모바일 변경 → 디자인 체크 실행.
  7. 실제 사용자 메뉴 하단의 관리자·비밀번호·로그아웃 아이콘 확인, 비밀번호 X·Escape로 이전 메뉴 복귀. 필수 변경 X는 로그아웃.
